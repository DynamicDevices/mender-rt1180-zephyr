# Security

## Reporting a vulnerability

If you believe you have found a security vulnerability affecting RT118x CM33 firmware built from this repository, please report it responsibly.

**Contact (placeholder):** `security@dynamicdevices.co.uk` — replace with your product-line published contact before fleet shipment.

**Engineering triage:** Vulnerability intake and remediation tracking for the CRA programme is described in [PROJECT-NOTES](mender-mcu-integration/PROJECT-NOTES.md) (WS3) and tracked in GitHub issue [#7 — Vulnerability triage process](https://github.com/DynamicDevices/mender-rt1180-zephyr/issues/7).

Do **not** open a public GitHub issue for undisclosed exploit details. Use the contact above or a private advisory channel once your product policy is defined.

Upstream components:

- [Zephyr vulnerability reporting](https://docs.zephyrproject.org/latest/security/reporting.html)
- [Mender security](https://docs.mender.io/overview/security)
